# 视觉目标卡 · 接口账号密钥轮换系统

> **性质**：结构化视觉目标卡（**不是**渲染图）。
> 本运行环境不具备图像生成能力，因此本目录**只保留结构化描述**，不放置占位图、不伪造「概念图」。
> 真实运行截图采集于 `docs/screenshots/`，由程序实际渲染产生，不得用本文件的内容冒充。

---

## ① 画面类型

**桌面窗口（JavaFX 21）+ AWT 系统托盘常驻**。

- 不做 Web 大屏、不做浏览器界面、不做导出的报告页。
- 窗口关闭后收进托盘继续订阅事件流；托盘不可用的院内机器降级为顶部常驻状态条。
- CLI（`--cli <cmd>`）是运维与排障通道，不是主入口。

## ② 三个状态

### 起始态 —— 「还没接上」

- 托盘出现图标，主窗刚展开。
- 窗口顶部只有一行「尚未订阅接口引擎事件流」和一个「接入事件源」按钮。
- 左栏通道树空、中栏时间轴空、右栏无结论卡。
- 底部心跳行显示「订阅：未连接」。
- **画面上「还没有数据」这件事必须一眼可见**——不靠空白让人自己猜。

### 首个可用瞬间 —— 「有数了」

- 接入后 30 秒内，顶部三枚关键数字从 0 跳到 **今日待处理 3 / 即将到期 1 / 已验证 12**。
- 「即将到期」区出现一张卡片：**一张对接证书**，卡面三行——
  - 通道名「卫健数据上报」
  - **剩余 3 天**（橙色 `#E67E22`）
  - **关联 4 条通道**
- 卡片右侧一行小字列出 4 个下游系统名。
- 点开卡片，下方出现该凭据最近 6 次失败记录（时间戳 + 错误类 + 一行脱敏报错）。

### 成形态 —— 「常驻工作台」

- 窗口稳定常驻，三栏结构：
  - **左栏** = 按到期紧迫度排序的凭据清单，每行左侧一条色带（红 = 已过期 / 黄 = 7 天内 / 灰 = 正常）；
  - **中栏** = 选中凭据的失败事件时间轴（每条失败一个圆点，点开是脱敏报错片段与证据引用）；
  - **右栏** = 根因结论卡（根因一句话 + 指认的具体凭据 + 置信提示 + 证据引用列表 + 「派发处置单」按钮 + 「已人工确认」勾选位）。
- 窗口底部常驻心跳行：订阅正常 / 断连、上次事件时间、队列深度。
- 队列逼近背压上限时，队列深度数字变黄并显示「即将拒收」。

## ③ 视觉语言

| 项 | 取值 |
|---|---|
| 主色 | `#1F4E79`（标题栏与表头） |
| 告警红 | `#C0392B`（已过期 / 致命失败） |
| 预警橙 | `#E67E22`（7 天内到期） |
| 正常绿 | `#27AE60`（已验证） |
| 背景 | `#F5F6F8` |
| 卡片底 | `#FFFFFF` + 1px `#E1E4E8` 描边 |
| 时间轴连线 | `#C7CDD4` |

- **字体族**：中文回退链 **Microsoft YaHei → PingFang SC → SansSerif**；
  时间戳、剩余天数、队列深度等数值用等宽 **JetBrains Mono**（缺失时回退 `monospace`），保证列对齐。
- **信息层级**：
  1. 顶部三枚关键数字（最大、最显眼，字号 28）
  2. 左栏色带清单（第二层，**色先于字**）
  3. 中栏时间轴（第三层，弱化但可点）
  4. 右栏结论卡（结论区，仅在选中凭据后出现，是「可带走」的那一页）
- **留白密度**：卡片间距 12px、卡片内边距 16px、行高 28px、表格行高 26px；
  一屏内可见 ≥ 12 条凭据行且不拥挤。
- **数字排版**：日期时间统一 `YYYY-MM-DD HH:mm`；剩余天数与队列深度右对齐、数值等宽。

## ④ 必须可达的约束

只允许出现**用当前依赖真能做出来**的元素：

- 全部用 JavaFX 标准控件实现：`TableView` / `ListView` / `ScrollPane` / `Label` / `Button` / `ToggleButton` / `ProgressBar` / `Circle`。
- **不引入** `WebView`、不做 3D / 粒子 / 动画特效、不引第三方图表库。
- 时间轴用**纵向 `VBox` + 圆点 `Circle`** 表达，不自绘折线 / 曲线图。
- 配色用 JavaFX `Color` 常量集中管理（design token），不散落硬编码色值。
- 字体用系统回退链，**不内嵌字体文件**。
- 托盘用 JDK 内置 AWT `SystemTray` + `TrayIcon`，不引额外依赖；退出走 `Platform.exit()`。
- 结论卡上的「置信提示」「已人工确认」是**静态标签 + 开关控件**，不做图表化呈现。
